# Journal demo identities

- **Journal of Achmage:** original typographic lockup. Navy `#002E6E`, blue `#0066B3`, teal `#00B5AD`, following the color values in the owner's brand notes. This is not a Hallym University journal or endorsement.
- **Journal of Command & Space:** the supplied CMDSPACE vector mark with a journal descriptor; teal `#007F79`, pink `#E985A2`. Its inclusion in this public demo package was requested by the project owner. The software MIT license does not grant rights to the CMDSPACE trademark.
- Both are demonstration presets, not publication or affiliation claims. PDFs contain vector artwork without raster images. SVG companions are for screen use.

To reproduce the lockups, run `python scripts/build-brand-wordmarks.py` with PyMuPDF installed. No commercial font files are required.
