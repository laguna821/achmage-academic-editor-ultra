# R-023 — 발행정보 빠른 수정과 연속 제목 간격

Date: 2026-09-16. Status: IMPLEMENTED / isolated-host and PDF checks; full 3.0 acceptance remains open.

## 편집자가 입력해야 하는 값

첫 페이지의 발행정보, 로고, 날짜·교신저자, 판권 영역을 클릭하면 같은 프로젝트의 구조화된 입력창을 연다. 값만 수정하고 글꼴·색·위치는 프리셋을 그대로 적용한다. DOI, 날짜, 저자 신원 등 원고에 없는 정보는 생성하거나 출판 PDF에서 가져오지 않는다.

- AOP/권호 전환: AOP는 권·호·쪽수 표시를 숨기되 입력값을 보존한다. 다시 권호로 전환하면 복원한다.
- 시작 쪽수는 편집자가 입력한다. 끝 쪽수는 실제 최종 PDF 페이지 수로 계산한다. 다음 논문 시작 쪽수도 화면에 표시한다.
- DOI는 ISSN 아래 세 번째 줄. Crossmark 링크는 같은 DOI를 사용한다.
- 접수·수정·승인일, 교신저자의 이름·이메일·여러 줄 주소를 수정할 수 있다.
- 판권 연도는 별도 입력할 수 있으며 비어 있으면 발행 연도를 따른다. 로고와 Crossmark 표시 및 브랜드 파일을 설정할 수 있다.
- 미리보기를 확인한 뒤 발행정보를 확정한다. 메타데이터, 페이지 수, 프리셋, 등록 글꼴이 바뀌면 확인이 무효가 된다. 오래된 미리보기에서 확정을 누르면 먼저 다시 조판하고, 새 화면을 본 뒤 다시 확정해야 한다.
- 최종 PDF 내보내기는 현재 발행정보 확인과 기존 오류·변경기록 검사를 모두 통과해야 한다. 검토용 PDF는 미확정 상태를 유지하며 만들 수 있다.

## 제목 사이 간격

원본 PDF의 연속 제목 36쌍에서 관찰한 글자 경계 간격 중앙값은 약 1.861pt다. 원본 103의 Methods 하단 609.0930pt와 Study setting 상단 610.9537pt의 차이는 1.8607pt다. 기존 본문→제목 앞 여백 12pt를 연속 제목 사이에도 적용하던 것을 분리했다.

- 단계별 본문→제목, 제목→본문, 제목→다음 제목 간격.
- `1:2`처럼 단계 조합별 예외. 0pt도 유효하며 기본값 복원이 가능하다.
- HNMR의 Calibri/Times 글꼴 프레임으로 측정한 연속 제목 기본 논리 간격 1.9525pt를 사용한다. 이는 PDF 글자 경계의 목표 약1.861pt와 구분되는 값이다. 다른 서체에서는 조정한다.
- 연속 제목을 함께 배치하고 다음 본문 최소 두 줄을 확보한다. 단 맨 위의 앞 여백은 생략한다.

## 검증

`tests/journal-publication.test.ts`: AOP 데이터 보존, 계산 쪽수, 판권 연도, 확정 무효화/undo, 단계별·조합별 간격과 검증.

`scripts/test-journal-host.mjs`: 격리 Obsidian에서 실제 미리보기 영역 클릭 → AOP → 시작23/판권2027 → 확정 → 권호 전환 → 재확정 → PDF 저장과 바이트 일치, 저장 프로젝트 재열기. 사용자의 실사용 볼트는 변경하지 않는다.

`scripts/check-journal-publication.py`: 실제 호스트 PDF 12개 검사. AOP의 권호/쪽수 숨김, 권호의 최종 쪽수, DOI 세 번째 줄, Crossmark 대상 DOI, 판권2027, 발행연도2026을 확인한다. 입력값은 모두 명시적인 가상 시험자료다.

미입력 발행정보는 여전히 사용자가 입력해야 한다. 투고 시스템 연동, 수정일이 없는 원고의 별도 상태 모델, DOI 전체 대조 큐(R-022), Markdown 입력 어댑터는 이 구현의 완료 범위가 아니다.
