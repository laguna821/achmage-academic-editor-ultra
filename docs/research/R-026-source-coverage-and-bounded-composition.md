# R-026 — 원본 대조, 출판본 비교와 제한된 조판 보정

Date: 2026-09-16. Branch: `3.0.0`. Baseline: published 2.6.1 `a31a191`.
Status: implementation, independent verification and preserved first-pass evaluation; no public release.

## 계약과 이전 결과의 정정

사용자는 과거 PDF의 불규칙한 위치를 외우는 방식 대신, 새로운 원고에도 적용할 통일 규칙과 차이 기록을 선택했다. 가로 글자폭의 작은 보정도 허용했다. DOCX 원본만 생성 입력으로 사용하고 출판 PDF는 비교 기준으로만 읽는다. 별도 Title/Figures/Tables 파일과 출판본 본문으로 누락 내용을 채우지 않는다.

R-025의 22편/18,149개 내부 검사 통과는 **원본 전체의 무누락 증명이 아니었다**. 그 검사는 이미 배치된 항목을 검사했으므로, 110번 원고의 연속 그림 4개가 배치 단계에서 빠진 상태도 통과했다. 이번 검사는 기대 목록을 원본 ZIP/XML에서 별도로 만들고, 가져온 모델과 실제 PDF를 각각 검사한다. 과거 통과 수치를 이 강화된 검사의 통과 수치로 재사용하지 않는다.

## 구현

- `coverage.ts`: 배치된 항목의 목록에서 출발하지 않고 프로젝트의 기대 문단·초록·제목·그림·표·행·셀·캡션·주석·확정 참고문헌을 대조한다. 원본 SHA-256 + XML 경로 + 그림 발생 순서로 추적한다. 기존 편집 ID는 유지한다. `rendered/transformed/excluded/unresolved`를 구별하며 미배치는 오류다.
- `audit-journal-source.py`: TypeScript 가져오기 코드를 호출하지 않는 별도 ZIP/XML 목록과 실제 PDF 글자 검사. 원본 파일 해시, 문단, 셀 원문, 각 미디어 발생을 대조한다. 이미지가 놓였다는 메타데이터만으로 그림 성공을 판정하지 않는다.
  - 저장된 `origin.text`가 원문과 같다는 사실만으로 통과시키지 않는다. 실제 가져온 내용과 비교하고, 각주 표지/초록 표제 이동 등 명시한 변환만 구별한다. Office 호환성 Choice/Fallback은 중복 본문으로 세지 않는다.
  - 본문 안의 이미지도 실제 PDF에 그려졌는지 검사한다. 원본에서 크게 지정한 삽화가 작은 인라인 썸네일로 바뀐 경우 별도 검토 실패로 기록한다.
- `check-journal-pdf-detail.py`: 셀의 실제 글자 경계, 원문 값, 줄·선·주석 간격, 본문과 float 간격, 머리말 선 침범에 더해 양쪽 단에서 동시에 이어지는 본문의 기준선 차이를 검사한다.
- `compare-journal-publication.py`: 문장 조각을 독립적으로 맞춰 페이지 수 변화가 뒤쪽 전체의 오차로 번지지 않게 한다. 가져오기 결함, 배치 결함, 원고/출판본 내용 차이, 통일 스타일 적용, 불명확을 구분한다. 글꼴·크기·줄 수·간격·좌표, 비교 PDF와 첫 세 페이지의 표시 이미지를 저장한다. 낮은 대응률은 자동 성공이 아니다.
- `bibliography.ts`: 확정 참고문헌도 개별 높이를 측정해 본문 배치와 마지막 단 맞춤에 포함한다. APA 엔진의 full citation을 그대로 사용해 이탤릭체를 다시 만들지 않는다. CSL 순서를 얻은 뒤 같은 순서로 라이브러리를 다시 공급하여 동일 저자/연도의 a/b도 맞춘다. DOI는 Hayagriva의 `serial-number.doi`로 전달한다.
- `quality.ts`, `typography.ts`, `balance.ts`: 새 HNMR 프로젝트에 보정을 켠다. 해당 설정이 없는 기존 프로젝트는 종전 동작을 유지한다. 고정 영역, 수동 나눔, 절 나눔, 항목별 보정 해제를 지킨다. 적용 전후 값과 사유를 편집 화면에서 확인·해제할 수 있다.
- `tableSemantics.ts`: 한 열의 비어 있지 않은 데이터 셀들이 명확한 수치일 때만, 측정된 정수부/소수부 폭으로 소수점 정렬을 적용한다. 원래 숫자, 부호, 자릿수, 괄호값, 유의확률 기호는 바꾸지 않는다. 모호한 혼합 열에는 추측한 의미 정렬을 적용하지 않는다.

## 제한과 선택 순서

| 항목 | 동작 |
|---|---|
| 단어 간격 | 기본 모양을 먼저 측정. 과도한 간격이 있는 문단에만 후보 생성 |
| 자간 | 최대 ±0.01em, 0.005em 단위 |
| 글자 가로폭 | 99–101%, 0.5% 단위. 글자 높이·크기 유지, 재줄바꿈 후 측정 |
| 적용 제외 | 수치 셀, 수식/첨자, 이미지, 브랜드, 확정 인용이 포함된 문단 |
| 기준선 | 프레임의 공통 본문 줄높이에 정렬. 연속 제목 묶음 뒤의 본문 시작선을 함께 맞춤 |
| 마지막 단 | 마지막 자유 텍스트 영역에서 본문·참고문헌 순서를 유지해 균형 후보 비교 |
| 줄높이/문단 여백 | 마지막 영역 양쪽 단에 같은 줄높이 보정(최대 ±0.2pt), 가변 문단 여백 최대 ±1pt |
| 그림·표 호출 | 명확한 첫 본문 호출; 없거나 제목 묶음에 속하면 원문 위치와 검토 항목 유지 |
| 전체 폭 위치 | 현재/다음 페이지 후보를 만들고 3페이지의 남은 본문 줄 수로 비교 |
| 탐색 | beam 32, 최대 4,000 확장. 시간 제한·난수로 다른 결과를 선택하지 않음 |
| 긴 표 | 고정 열 너비, 머리행 반복, 행/주석 원문 범위와 연속 조각 유지 |

이것은 문서 전체의 수학적 최적해를 증명하는 엔진이 아니다. 본문의 작은 보정, float의 유효한 사각형 후보, 마지막 자유 영역의 균형을 제한된 탐색으로 개선한다. 앞쪽의 고정 배치를 마음대로 옮겨 마지막 페이지를 맞추지 않는다. 제약 때문에 높이를 맞추지 못하면 검토 사유를 남긴다.

## 실제 회귀에서 추가로 고친 문제

1. 연속 그림 배치가 현재/다음 두 페이지를 이미 채웠을 때 남은 그림을 버리던 문제.
2. 뒤늦게 반대쪽 단을 채우는 본문이 전체 폭 표의 윗간격을 침범하던 문제. 표 앞의 최소 공간을 양쪽 단에 예약한다.
3. 페이지 상단에 있어도 그림으로 잘린 낮은 영역에는 문단이 들어가지 않는 경우. 다음 유효 영역으로 이동한다.
4. 각주가 원고 뒤에 추가된 후 참고문헌으로 오인되던 문제. 각주 역할과 원문을 보존하며 각 문단 경로도 구별한다.
5. 벡터 EMF의 비율을 모르면서 페이지 높이만큼 공간을 예약하던 문제. 프레임 비율을 읽고 픽셀 해상도와 구분한다.
6. 확정 참고문헌의 DOI 전달 필드와 동일 연도 a/b 순서.
7. 수백 가지 글자 후보를 같은 WASM 세션에 누적한 뒤 장문 조판이 실패하는 문제. 정상 문단에는 추가 후보를 만들지 않고, 후보 측정 단계가 끝나면 세션을 다시 연다.
8. 첫 평가 후 확인한 일반 가져오기 결함: 그림과 명확한 Figure 캡션이 같은 문단이면 독립 그림과 그 그림의 캡션으로 분리한다. 다음 그림에 잘못 붙이지 않으며 원본 경로와 이미지 해시를 보존한다.
9. 구식 Symbol 글꼴의 α/β/화살표 등이 대체 문자열로 남던 문제. 공개 매핑 중 Unicode 후보가 하나인 항목만 변환한다. 복수 의미, 사적 영역 문자와 Wingdings 등 다른 글꼴을 추측해 같은 매핑에 넣지 않는다. 원본 데이터의 이용 고지를 함께 보존한다.

## 검증 구조

개발 코퍼스는 10(1), 9(2), 9(1)의 원본 manuscript 22편이다. 새 평가용 파일 6개를 파일명과 해시로 고정했으나, 첫 출력 확인 후 8(2) 3편이 서평임을 발견했다. 해당 파일과 첫 결과를 삭제하지 않고, 연구 배경/방법/결과/참고문헌이 있는 8(2)의 주 원고 3편을 추가 선정했다. 별첨/번역/재가공 Figure·Table 파일은 쓰지 않았다. 추가 3편을 포함한 Original Article 6편의 첫 출력은 첫 고정 규칙으로 생성했고 그 결과에 맞춰 규칙을 바꾸지 않았다.

첫 평가에서 드러난 Symbol 및 같은 문단 그림/캡션의 일반적 가져오기 문제를 수정한 뒤 **두 번째 규칙과 회귀 결과**를 별도로 남겼다. 이 6편을 다시 출력한 결과를 새로운 미관측 원고의 첫 통과율로 부르지 않는다. 최초 규칙/선정/출력은 그대로 보존한다.

실행/결과 파일은 모두 무시되는 `test-artifacts/journal/` 안에 둔다. 원고, 글꼴 바이트와 전체 비교 PDF는 저장소에 넣지 않는다.

- `quality-corpus-results.json`: 개발 원고별 결과와 코드 해시.
- `quality-*-source-audit.json`, `quality-*-detail-check.json`: 기대 목록과 실제 PDF 검사.
- `quality-*-publication-comparison.json/.pdf`: 내용으로 대응시킨 출판본 비교.
- `holdout-selection.json`, `rules-freeze.json`, `holdout-first-pass.json`: 평가 원고 선택·규칙 고정·첫 결과. 첫 결과를 덮어쓰지 않는다.
- `holdout-supplement-selection.json`, `holdout-supplement-first-pass.json`: 잘못 선정한 서평을 보존한 채 추가한 Original Article 3편.
- `rules-freeze-r2.json`, `holdout-regression-selection.json`, `holdout-regression-results.json`: 일반 결함 수정 후 동일 6편의 회귀. `first-freeze-development/`에는 개발 원고의 첫 규칙 결과도 보존한다.
- `source-verification-v2.r1.json`, `*-source-audit-v2.json`: 원문 문자열/기호/인라인 그림 검사를 강화한 첫 출력 재검증. 최초 약한 검사 결과와 분리한다. 최종 감사에는 PDF 해시와 공개 Symbol 매핑 해시도 포함한다.
- `quality-review.md`, `quality-validation-summary.json`, `quality-before-after.pdf`: 최종 검토 목록, 단계별 집계, 대표 사례 전후 비교.
- `quality-reference-checks.json`: 실제 PDF의 책/논문/편저서 글꼴, a/b, DOI와 링크.
- `quality-repro-103-repeat-check.json`, `quality-repro-103-reimport-check.json`: 같은 프로젝트의 PDF 바이트 재현성과 신규 ID로 재가져오기 후 의미/좌표 재현성.

최종 집계는 아래 검증 로그에 기록한다. 원본 대조 통과, 출판본 차이 분석 완료, 편집자 확인 완료, 배포 가능은 서로 다른 상태다.

## 남는 사람의 판단

제목·교신저자·발행일·DOI 등 원본에 없는 발행 정보를 출판 PDF에서 몰래 채우지 않는다. 긴 러닝 헤더의 축약, 불명확한 표 머리글/유의수준, 미지원 Office 차트, 저자가 제공하지 않은 데이터·그림, 저자 수정의 채택 여부는 편집자가 확인한다. 원고의 의미나 수치를 추측해서 바꾸는 로직은 없다.

자료 종류별 APA의 전 범위, Crossref 비교/교정 큐(R-022), Markdown-to-journal 입력 어댑터와 임의의 출판사 첫 장 마스터는 별도 남은 계약을 유지한다. 이번 검증으로 그 기능들까지 완료됐다고 주장하지 않는다. macOS 실기 검증은 사용자의 기존 결정에 따라 필수 조건에서 제외하며 CI는 유지한다.

## 근거

- [Typst full citation API](https://typst.app/docs/reference/model/cite/): 전체 서지 항목 형식과 APA 스타일 지원.
- [Hayagriva file format](https://github.com/typst/hayagriva/blob/main/docs/file-format.md): DOI의 `serial-number` 매핑.
- [Typst scale](https://typst.app/docs/reference/layout/scale/): 가로 보정 시 reflow를 함께 사용.
- [Typst columns](https://typst.app/docs/reference/layout/columns/): 기본 columns는 자동 균형 조판을 제공하지 않으므로 명시적으로 배치.
- [Unicode의 Adobe Symbol 매핑](https://www.unicode.org/Public/MAPPINGS/VENDORS/ADOBE/symbol.txt): 같은 코드에 복수 Unicode 값이 있는 경우와 사적 영역 매핑을 제외하고 사용. 다른 기호 글꼴에는 적용하지 않는다.
- 원본 경계, APA 표/주석 근거와 출판 마스터는 R-020–R-025 참조.

- 110번의 원본 그림 6개가 6개 모두 PDF에 배치됐다. 이전 내부 검사에서 놓쳤던 누락 4개를 복구했다. 103번 마지막 자유 영역의 두 단 높이 차이는 조정 직전 445pt에서 8pt로 줄었고, 해당 보정에 줄높이나 자간 변형은 필요하지 않았다.
- 출판본 비교 PDF/기계 보고서 22개를 생성했다. 낮은 대응률 또는 원고/출판본 내용 차이는 검토 대상으로 남는다. 출판본과의 픽셀 동일성 또는 모든 옛 줄바꿈 재현을 통과했다고 주장하지 않는다.
- JavaScript **308 tests / 19 suites**, lint, TypeScript/production build, bundle, Community 및 버전/릴리스 파일 일치 검사 통과. 실제 release 발행은 하지 않았다. 배포 의존성 감사의 알려진 취약점 0건.
- 기존 Markdown A/B × 표 폭 × 절 나눔 PDF 회귀 및 내보내기 UI 회귀 통과. 새 저널 엔진의 본문 분할, 긴 초록, 주석, 수동 고정/절 나눔, 표 폭 합성 사례와 APA 참고문헌 PDF 검사 13건 통과.
