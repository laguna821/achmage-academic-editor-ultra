# R-025 — APA 표 주석 문법과 숫자 의미 단위

Date: 2026-09-16. Status: implemented bounded formatting and review findings; complete APA semantic validation remains open.

## 근거

[Purdue OWL의 APA 7 표 안내](https://owl.purdue.edu/owl/research_and_citation/apa_style/apa_formatting_and_style_guide/apa_tables_and_figures.html)를 재확인했다. 일반 설명, 특정 셀 설명, 유의확률 설명 순서이며 `Note1`, `Note2`가 아니다. 일반 설명은 이탤릭체 `Note.`로 시작한다. 개별 설명은 소문자 위첨자, 확률 설명은 별표 등의 기호와 이탤릭체 p를 사용한다. 같은 기호의 유의수준은 문서 전체에서 일관돼야 한다. APA 제출 원고의 표 주석은 두 줄 간격이다.

[University of Mary Washington의 표·그림 안내 PDF](https://academics.umw.edu/speaking/files/2024/10/Formatting-Tables-and-Figures-in-APA.pdf), p.2–3도 한 유형에 여러 설명이 있을 때 같은 문단에 묶는 예시를 제공한다. 이 보조 안내의 모든 표를 한 페이지에 넣으라는 단순화는 긴 저널 표의 분할 정책으로 채택하지 않았다.

HNMR 완성 인쇄본은 APA 제출 원고와 동일한 간격을 요구하는 프리셋이 아니다. `tableNotes.spacing`은 저널 간격과 APA 원고 **주석의** 두 줄 간격만 선택한다. 이 옵션이 논문 전체의 APA 준수를 보증하지 않는다. 새 HNMR 기본 추가 간격 3pt는 가독성 개선값이며 APA가 정한 수치 또는 기존 모든 HNMR PDF에서 측정된 값이라는 뜻이 아니다.

## 수정

- 서로 독립된 주석 블록에 문단 사이 leading이 빠져 설명과 위첨자 별표가 붙어 보였다. 이제 실제 줄높이와 글자 크기 차이 + 저널 추가 간격을 유형 사이에 적용한다. 기본 8pt/10pt 주석에서 블록 간격은 5pt, 한 줄 설명과 다음 확률 줄의 기준선 차이는 13pt다.
- 일반·개별·확률 유형별로 한 문단을 만든다. `Note:`/`Notes.`를 `Note.`로 표시하고, 같은 유형의 원본 문단 순서는 유지한다. 원본 Paragraph, Inline, ID, DOCX는 변경하지 않는다.
- 명확한 확률 표현 목록에 한해 p 이탤릭체, 관계 기호 양옆 간격, p값의 선행 0 생략, 표현 사이 마침표를 적용한다. 비교 연산자, 기호, 유효 숫자 자릿수, 역치의 값은 보존한다. 예: `* p< 0.050; ** p< 0.01.` → `*p < .050. **p < .01.`
- 일반 설명 문단의 **문장 경계 뒤**에 명확한 확률 목록만 남는 경우 별도 확률 문단으로 분리한다. 본문 문장 안의 표현을 뜯어내지 않는다. `2-tailed`, N, 조건 설명이 섞여 있으면 원문을 유지하고 검토 항목을 표시한다.
- 출력 그룹은 원본 주석 ID와 UTF-16 시작/끝 범위를 기록한다. 한 원본 문단을 두 유형으로 나눈 경우도 모든 원본 문자가 정확히 한 번 대응되는지 검사한다. PDF 문자열은 별도의 Python 규칙으로 원본에서 유도한 예상 표기와 대조한다.
- 유형 사이 간격과 줄높이를 포함한 전체 주석 높이를 마지막 표 조각의 행 선택·페이지 배치에 사용한다. 주석은 마지막 조각 안에 포함하며 표 아래 본문 간격도 유지한다.
- 설정 UI에서 저널/두 줄 간격과 저널 유형 사이 추가 간격을 바꾸고 프로젝트에 저장할 수 있다. 기존 프로젝트에는 저널 기본값을 적용한다.

## 표의 읽기 단위

- 기본 열 폭은 전체 숫자 표현을 함께 놓을 수 있는 실제 글꼴 최소 폭을 우선한다. 폭이 좁을 때도 소수, 괄호값, 값에 붙은 별표를 글자 단위로 쪼개지 않는다. 계수와 괄호 안 SE 사이에서는 필요한 경우 줄을 바꿀 수 있다.
- 명확한 숫자 셀에서만 적용한다. 설명·단위·헤딩의 뜻을 임의로 추정하지 않는다. 수치·정밀도·통계량을 바꾸지 않는다.
- 선택한 폭에 단일 숫자 단위도 들어가지 않으면 조판 오류로 남긴다. 폰트 축소나 숫자 중간 절단으로 숨기지 않는다.
- 숫자 셀의 기호 설명 누락, 같은 표 또는 표 사이의 유의수준 차이, 조건이 섞인 주석을 검토 경고로 제공한다. 이 경고는 과학적 오류의 확정 판정이 아니다. 단측·양측 또는 별도 모델의 차이를 자동 교정하지 않는다.

## 검증

- 원본 manuscript DOCX 22편, 표 69개 재출력. PDF 세부 검사 **22/22, 18,149건 통과**. 일반·개별·확률 출력 그룹은 17개다. 새 숫자 단위 폭 오류는 없다.
- 검사 범위: 기존 셀 문자열·글자 경계·선·본문 간격에 더해, 원본 주석 범위의 누락/중복, 유형 순서, 유형별 문단 수, 실제 주석 글꼴/이탤릭체, 줄높이, 영역 폭, 유형 사이 글자 경계 충돌, 마지막 표 조각 안의 배치를 포함한다.
- 사용자 제시 Table 3: 유형 블록 사이 5pt, 기준선 차이 13pt, 실제 PDF 글자 경계 사이 약 3.511pt. 해당 원고의 검사 760건 통과. 통계 행 재구성에 대한 편집자 확정은 여전히 필요하다.
- 41행 합성 표 + 긴 일반 설명 + 개별 설명 2개 + 여러 확률 목록 + 혼합 문단: 저널 간격 **356건**, 두 줄 간격 **358건** 통과. 자동/한 단/전체 폭, 머리행, 좁은 셀 회귀 PDF **437건** 통과.
- JavaScript **299 tests / 19 suites** 통과. lint, TypeScript/production build, bundle, Community 검사 통과.
- 격리한 실제 Obsidian에서 주석 설정 선택·변경·저장·재로딩, 조판, 미리보기/내보내기 동일 PDF 바이트 확인. 사용자 실사용 볼트에는 설치하지 않았다.
- 코퍼스의 새 의미 검토 항목: 명확한 기호 설명을 못 찾은 표 4개, 조건이 섞인 주석 1개. 기존 러닝 헤더 넘침·미지원 내용·미확정 원고 구조 등 편집 항목도 유지한다. 검사 통과를 배포 준비 완료나 출판 PDF와 완전 동일하다는 뜻으로 사용하지 않는다.

Ignored artifacts: `test-artifacts/journal/hnmr-table-notes-review.pdf`, `hnmr-table-notes-current.png`, `hnmr-table-notes-detail.png`, `manuscript-only/notes-composition-results.json`, 두 합성 간격 모드와 원고별 PDF·검사 JSON. 전후 PDF의 표는 실제 원고로 생성한 개발 검토본이며 행 대응은 편집자 확인 전 후보다.

## 남은 범위

임의의 Word 표를 통계 유형별 완전한 의미 구조로 복원하는 작업, 모든 다층 머리글 관계, 소수점 정렬, 명시되지 않은 단위·약어·유의수준, 본문 호출과 표 값의 일치, 수치 자체의 과학적 타당성은 아직 전체 자동 검증이 아니다. 기존 R-024의 원고 보존·검토 가능한 재구성과 이번 표시 정규화·배치를 바탕으로 확장한다.

후속 [R-026](R-026-source-coverage-and-bounded-composition.md)에서 명확한 수치 열의 소수점 정렬과 호출 기준 배치를 추가했다. 위 22/22·18,149건은 당시 배치된 개체의 내부 검사 통과이며 원본 전체의 무누락 증명이 아니다. 독립 원본 대조, 더 강한 PDF 검사, 새 원고의 첫 평가 및 후속 회귀 집계는 R-026을 따른다.
