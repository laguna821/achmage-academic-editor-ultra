# R-024 — APA 표 서식, 주석 결합, 원고 표 구조 정리

Date: 2026-09-16. Status: IMPLEMENTED bounded rules / broader APA semantic acceptance open.

## 근거와 정책

[Purdue OWL APA 7 표 안내](https://owl.purdue.edu/owl/research_and_citation/apa_style/apa_formatting_and_style_guide/apa_tables_and_figures.html)는 필요한 가로선, 세로선·셀별 테두리의 회피, 머리글 정렬, 표 아래 일반·개별·유의확률 주석 순서를 설명한다. 0.12mm/0.15mm를 APA의 고정 선 두께로 확인하지 않았다.

HNMR 기본값은 검정 실선 **0.4pt ≈ 0.141mm**다. 표 위·머리행 아래·표 아래에 같은 선을 사용하며 모든 데이터 행에 가로선을 그리지 않는다. 설정에서 전체 두께·색을 일괄 변경할 수 있고 세부 두께 및 모든 행 구분 모드도 유지한다. 이는 새 통일 프리셋 정책이며 역사적 PDF 모든 선의 복제라는 뜻이 아니다.

## 실제 원고에서 수정한 결함

1. **이전 수정 기록의 병합 속성 혼입.** 현재 셀 속성에 gridSpan이 없을 때 하위 tcPrChange의 과거 gridSpan을 읽어 셀을 잘못 병합했다. 현재 속성의 직접 자식만 읽는다. 과거 속성·표 격자 변경 기록은 보존하며 미해결 변경 경고를 유지한다.
2. **열 너비와 실제 글자 넘침.** 실제 등록 글꼴로 비분리 단어 폭을 측정하고 병합 격자를 반영해 열을 고정한다. 모든 조각이 같은 폭을 쓴다. 넘치는 단어는 측정한 단위로 줄바꿈하며 크기를 줄이거나 글자를 자르지 않는다. 상·하첨자는 문맥적 줄바꿈 박스로 다시 감싸지 않아 기준선이 두 번 이동하는 결함을 방지한다.
3. **잘못된 좁은 폭 선택.** 전체 폭에서도 긴 단어의 최소 폭 합계가 크지만 표 높이가 25% 이상 줄어드는 경우 전체 폭을 선택한다. 수동 한 단/전체 폭 선택은 우선한다. 작은 숫자 표는 한 단으로 유지한다.
4. **불필요한 셀 좌우 여백.** 최소 내용 폭이 부족할 때 좌우 패딩을 최대 지정값에서 0.5mm까지 줄인 뒤 줄바꿈한다. 사용자가 지정한 패딩이 더 작으면 그 값을 유지한다. 위아래 패딩과 본문 사이 4mm 공간, 글자 크기는 유지한다.
5. **주석 분리.** 기존에는 Note.만 인식해 `* p < .05`를 본문에 흘렸다. 일반·명시적 위첨자 개별·유의확률 주석을 원본 문단과 함께 연결한다. 빈 문단은 건너뛰되 일반 본문을 주석으로 추측하지 않는다. 주석은 마지막 표 조각의 높이에 포함하고 바로 아래 기본3pt 간격으로 둔다. 통째로 들어가지 않는 행의 읽기용 대체 출력에도 주석을 보존한다.

## 병렬 통계값 정리 후보

원본85의 Table3은 각 변수의 다섯 통계값을 한 셀의 다섯 문단에 몰아넣고, 머리행과 본문의 격자 경계도 달랐다. 원본 격자를 그대로 그리는 것만으로는 변수와 수치의 행 정렬이 깨졌다.

`normalizePackedTable`은 다음 조건에서만 후보를 만든다.

- 세로 병합이 없고, 적어도 세 셀에서 같은 수의 비어 있지 않은 문단이 반복된다.
- 첫 열 이외의 내용은 숫자·통계 기호로만 구성된다.
- 동일한 논리 셀 수를 가진 앞 머리행이 존재한다.
- 다른 모든 행의 경계는 그 머리행 격자에 정확히 대응한다.

후보는 값을 만들거나 고치지 않고 문단을 실제 행으로 옮긴다. 원본 행·열 폭, 원본 문단 ID, 원본 셀→새 셀 관계를 보존한다. 유일한 순서 기반 대응 추정은 **원본 비교 후 확인해야 하는 오류**로 남긴다. 개체 패널에 정리 전 셀 보기, 대응 확정, 원래 구조 복원을 제공한다. 셀/행 편집은 이전 확정을 무효로 만들며 undo로 되돌릴 수 있다. 조건에 맞지 않는 표는 이 경로로 자동 재구성하지 않는다. 실제22편 중 이 후보가 적용된 표는1개다.

## 검증과 범위

- 22개 원본 manuscript DOCX에 포함된69개 표와 그림을 다시 조판했다. 별도 Figure/Table/Title 파일이나 출판 PDF의 논문 내용을 생성 입력으로 사용하지 않았다.
- 현재 PDF 검사에서22편 모두 통과. 세부 수치는 R-021의 최종 실행 기록을 따른다. 검사 통과는 원본 출판 PDF와의 완전 동일성 또는 모든 통계 관계의 의미 검증을 뜻하지 않는다.
- PDF에서 실제 셀 문자열·글자 경계, 주석의 단일 출현과 마지막 조각 포함, 선의 색·두께·실선·수평 위치를 검사한다. PDF의 선 끝은 두께의 절반씩 연장되므로 실제 그리기 경로와 콘텐츠 폭을 구분한다. 반대쪽 단에 놓인 다른 표의 선을 섞어 세지 않는다.
- 합성 41행 표는 마지막 조각의 설명·확률 주석과 함께 검증한다. 수동/자동 폭 및 작은 숫자 표의 한 단 유지도 확인한다.
- EMF 안의 단일 무손실24bit RGB 비트맵을 PNG로 복원하는 제한된 경로로 원본87을 조판했다. 원본 EMF도 보존한다. 임의 벡터 EMF 변환을 구현했다고 주장하지 않는다. 픽셀 순서와 잘린/지원하지 않는 레코드의 거부를 단위 시험한다.

**남은 APA 의미 작업:** 모든 통계 유형별 표 스키마, 소수점 정렬, 불일치 유의수준/별표 대조, 단위·소수점의 과학적 적절성, 약어 설명과 본문 호출, 안전한 제목 대소문자 교정, 모든 다층 머리글 및 예외적 원고 구조. 값이나 의미가 모호하면 확인 항목으로 남겨야 하며 완벽한 자동 APA 교정 완료로 표시하지 않는다.

후속 [R-025](R-025-table-note-grammar-and-readable-values.md)에서 주석 유형별 문단 간격, 일반 표제·확률 표현 표시 정규화, 원본 범위 대조, 숫자 단위 줄바꿈, 명확한 별표/유의수준 대조 경고를 구현했다. 이 기록의 위 목록 중 명시적 기호 대조는 제한된 규칙으로 진행됐으며 과학적 의미의 완전 검증은 여전히 열려 있다.
