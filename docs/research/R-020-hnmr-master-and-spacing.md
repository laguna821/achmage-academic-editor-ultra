# R-020 — HNMR 마스터·서체·세부 간격의 출력 계약

- 기준: 공개 2.6.1 이후 로컬 `3.0.0` 개발 중. 정식 배포 검증 완료를 뜻하지 않는다.
- 갱신: 2026-09-16. R-018 조사와 R-019 구현 계약을 구체화한다.
- 사용자 보강: 로고·Crossmark·판권·초록/교신저자 패널·역할별 서체를 원본 수준으로 적용하고, 첫 줄 들여쓰기와 표/그림 주변 여백을 포함한 미세 조판을 검사한다.

## 1. 증거와 재현 범위

22편/335쪽의 내려받은 PDF를 다시 사용했다. `scripts/inspect-hnmr-spacing.py`는 글자 좌표, 선행 공백, 헤딩과 본문 간격 및 캡션 후보를 추출한다. 캡션 자동 검출에는 본문의 “Table 3 presents…”도 섞일 수 있으므로 통계를 그대로 규칙으로 채택하지 않는다. 아래 대표 쪽은 렌더링을 확대해 확인했다.

- [10(1), 23–35쪽 논문](https://hnmr.org/upload/pdf/hnmr-2026-00094.pdf): 첫 페이지 전체 마스터, PDF 7쪽의 들여쓰기와 Results 전후 간격.
- [10(1), TikTok/Douyin 논문](https://hnmr.org/upload/pdf/hnmr-2026-00122.pdf): 로컬 `v10-1-article-108.pdf`, PDF 8쪽의 한 단 표 두 개와 주변 본문. URL과 로컬 파일 대응은 연구 corpus.json과 대조했다.
- [9(1), 1–20쪽 논문](https://hnmr.org/upload/pdf/hnmr-2025-00052.pdf#page=10): 그림 두 개, 표, 주석, 그 아래 2단 본문과 연속 헤딩.
- 로고는 사용자가 보관한 `HMRI 로고 2024.pdf`에서 벡터로 추출했다. Crossmark는 출판 PDF의 해당 마크만 추출했다. 경로·원본 해시는 `assets/journal/provenance.json`에 기록한다.

원고·글꼴 바이너리·조사 PDF는 공개 소스에 포함하지 않는다. 검사 산출물은 무시되는 `test-artifacts/journal/` 아래에 둔다.

## 2. 첫 페이지 마스터 — 구현 및 실측 대조

| 역할 | 적용 값 |
|---|---|
| 판형 | 182 × 257mm |
| 제목 | Calibri Bold 15/18pt |
| 본문 | Times New Roman 10/12pt |
| 초록 | Garamond 8.3/9.13pt; 고정 폭 104.273mm, 가변 높이 |
| 교신저자·날짜 | Gill Sans MT 7.5/9pt; 라벨은 굵은 녹색 |
| 판권 | Gill Sans MT 10/12pt |
| 첫 페이지 상·하단 선 | 4pt, `#00663e`, 원본 좌표 |
| 후속 페이지 상단 선 | 2pt, 원본 좌표 |
| 러닝 헤더·쪽수 | Gill Sans MT / Arial 9.3pt |

발행 정보, 제목, 선, 판권, 초록 패널은 대표 출판본 좌표를 기준으로 만들었다. 저자 수/제목/초록 길이에 따라 아래 영역을 실측 재배치한다. 긴 초록은 같은 폭·서체·배경의 패널로 다음 페이지에 이어지며 키워드와 교신저자 정보를 버리지 않는다. 로고/마크 자산, 색, 위치, 선 두께, 문구, 22개 텍스트 역할의 글꼴·크기·줄높이·정렬·자간·들여쓰기는 프리셋에서 따로 편집하고 JSON으로 보관한다.

사용자 후속 확인에 따라 초록·교신저자는 **하나의 행, 같은 위·아래 경계**로 배치한다. 행 높이는 두 영역의 필요 높이 중 큰 값이다. 초록이 짧아도 회색 박스는 교신저자 영역의 바닥까지 늘어나며, 교신저자 글줄을 벌리거나 실선을 추가하지 않는다. 본문은 이 공통 바닥 아래에서 시작한다. 22편의 첫 페이지에선 초록이 대체로 더 길었다. PDF에서 테두리 없는 원본 편집 프레임 자체의 높이를 추출할 수 있다는 주장은 하지 않는다. 동일 프레임 규칙은 사용자가 확인한 제작 방식에 근거한다.

### 실제 발견하고 수정한 문제

Typst의 양수 `bottom-edge:0.2em`을 사용해 목표 줄높이보다 실제 기준선 간격이 짧아졌다. 음수 하단 경계를 사용하고 전체 줄 프레임을 1em으로 명시했다. 본문 10/12pt 세 줄의 측정 높이 34pt를 실제 WASM 시험에서 검사한다. 설정 문자열이 있는지만 검사하지 않는다.

`check-hnmr-master.py`는 생성 PDF를 다시 읽어 22개 수치(서체별 줄높이, 좌표, 선 두께·폭, 초록 폭·높이, 판형)를 출판본과 대조한다. 추가로 역할별 글꼴·크기·색과 Crossmark 링크를 확인한다. 대조용 본문은 공개 PDF에서 가져온 기하학 시험 자료다. 저자 DOCX의 완전 변환 검증이 아니다. 원본과 달리 단 사이 4mm를 적용하므로 줄바꿈·최종 쪽수 일치도 주장하지 않는다.

숫자는 “APA가 4mm를 요구한다”는 뜻이 아니다. 원본 관찰과 사용자의 공간감 요구를 바탕으로 정한 HNMR 통일 프리셋 값이다. 사용자는 각각 바꿀 수 있다.

## 4. 검증 산출물과 현재 한계

- `master/hnmr-master-comparison.pdf`: 출판본과 첫 페이지/후속 페이지 마스터 대조. 22개 수치 및 추가 서체·색·링크 검사 통과.
- `hnmr-long-abstract.pdf`: 대표 초록을 6배 늘린 시험. 폭을 유지하며 3쪽 결과로 흐르고 초록 문자 누락 없음.
- `hnmr-spacing.pdf`: 실제 HNMR 서체를 등록한 가상 원고. 한 단 표, 표 주석, 전체 폭 Figure와 주변 본문. DOI가 없는 가상 자료라는 검사 항목을 보존한다.
- `check-journal-pdf-detail.py`: 생성 PDF에서 문단·셀 텍스트를 재추출하고 첫 줄 위치, 이어지는 문단 무들여쓰기, 표/그림 위아래 간격 검사. HNMR 간격 시험 **64개** 통과(초록·교신저자 동일 행과 실제 회색 박스 높이 4개 포함). 일반 긴 표 시험 **176개**, 긴 초록 시험 **18개** 통과. 모두 최신 코드로 다시 생성한 PDF를 검사했다.
- 실제 격리 Obsidian 호스트: 글꼴 14개 등록, 편집·저장·다시 읽기, 조판 및 미리보기/내보내기 PDF 바이트 일치 확인. 사용자 실사용 볼트는 변경하지 않는다.
- 원고 구획 가져오기 수정 후 회귀 테스트 **273개**, lint·타입/빌드·bundle·Community 검사 및 격리 Obsidian 호스트 재실행 통과. 실제 원고와 출판본 전체 대조는 [R-021](R-021-manuscript-only-fidelity.md)에 따라 별도로 진행하며 아직 통과하지 않았다.

이 문서는 첫 페이지와 간격 보강의 근거다. R-019 전체 수용 조건이나 3.0.0 출시 완료 선언이 아니다. 최종 페이지 균형, 어색한 양쪽 맞춤, 전체 원고의 의미 보존, 모든 표/그림·APA 예외는 별도 실패 사례와 함께 남겨 두어야 한다.

## 5. 소제목·상단 넘침·오른쪽 첫 줄 정렬 보강

- 원본 103의 2차 제목 `Sampling and data collection` 앞 글자 경계 간격은 약15.68pt, 91의 큰 제목 앞은 대표적으로 약12.34pt였다. 서체 프레임과 앞 문단의 끝 위치가 달라 단순한 빈 문단 개수로 재현하지 않는다. 프리셋의 앞12pt/뒤1pt를 실제 제목 역할에 적용한다. DOCX에서 `2. METHODS`, `2.1 Study setting and design`을 일반 문단으로 가져오던 오류를 수정하고, 추정 계층은 확인 경고와 원문을 보존한다.
- 긴 논문 제목을 러닝 헤더로 사용하면 두 줄이 상단 선과 겹쳤다. 실제 서체로 높이와 줄바꿈 없는 자연 폭을 모두 측정한다. 검토본은 맞는 길이의 줄임표 머리말을 사용하며 `running-header-overflow` 오류를 남겨 최종 내보내기 전에 짧은 머리말을 지정하도록 한다. 원문 제목은 변경하지 않는다. 공백 없는 긴 문자열도 시험했다.
- 원본 22편의 오른쪽 정보 영역은 날짜가 첫 줄이고 교신저자 라벨은 그 아래다. 10(1)과 9(2)의 다수 표본에서 첫 글자 경계는 회색 박스 위에서 약1.87pt 아래, 9(1)은 약−0.74pt였다. 이는 역사적 서체/마스터 차이다. 통일 프리셋은 기존1.87pt를 유지한다.
- 날짜가 없는 원고에서는 `Corresponding author:`가 오른쪽 첫 줄이다. 기존 코드가 비어 있는 날짜 뒤에도10.5pt 간격을 넣던 오류를 수정했다. 날짜가 있으면 그 사이 간격을 유지하고, 없으면 첫 줄을 지정된 박스 상단 위치에 맞춘다. 양 패널의 공통 위·아래 경계 규칙도 유지한다.
- 최신 실제 원고 21개 PDF에서 위 세 항목의 검사 통과. 전체 세부 검사는15편만 통과했으며, 남은 표/EMF 문제는 R-021에 기록한다.
- `hnmr-detail-regression.pdf`: 긴 비분리 머리말, 제목 계층, 날짜 없는 교신저자 영역, 자동/한 단/전체 폭 표를 시험해403개 검사 통과. 좁은 표에서도 일반 긴 단어가 셀 안에서 줄바꿈되는지 확인한다. 임의의 긴 URL/통계표 전체 해결을 뜻하지 않는다.
- 첫 페이지 마스터22개 수치와 추가 서체·링크 대조 재통과, 긴 초록31개 검사 통과. 회귀 테스트283개/19개 묶음, lint·타입/빌드·bundle·Community 검사 및14개 글꼴을 등록한 격리 Obsidian 호스트 검증 통과. 실제 사용 볼트는 수정하지 않았다.

## 6. 연속 제목과 발행정보 확인 — 후속 검증

R-023의 단계별/조합별 간격 설정으로 Methods→하위 제목 사이를 본문→제목 앞 여백과 분리했다. 원본103의 실제 글자 경계 간격1.860718pt에 대해 최신 생성 PDF는1.860779pt였다. 같은 HNMR 글꼴에서 측정한 한 쌍의 검증이며 모든 사용자 글꼴의 보장이 아니다.

미리보기 첫 페이지의 발행정보·브랜드·교신저자·판권 영역에서 값을 수정하고 확인한다. 실제 격리 호스트에서 AOP/권호 전환과 확인 무효화를 실행했으며, 출력 PDF의 DOI 줄·Crossmark 대상·발행/판권 연도·쪽수 표시12개 검사도 통과했다. 마스터22개 수치와 긴 초록31개 검사 재통과. 현재293개 회귀 시험 통과.
