# Academic Editor Ultra 0.2.0 — 통합 원고 편집

Word와 Markdown 모두 왼쪽에서 원고를 수정하고 가운데 PDF로 확인합니다. Markdown 모드에서도 교신저자 입력을 위해 YAML 키를 찾아 원래 노트로 돌아갈 필요가 없습니다.

## 바뀐 사용 순서

1. 원고를 열고 왼쪽 **기본 정보 / 저자·소속 / 초록·키워드 / 발행정보·교신저자 / 말미 선언문 / 머리말·판권**에서 입력합니다.
2. 위쪽 **↻ 미리보기 갱신**으로 지면을 확인합니다. 미리보기의 해당 영역을 누르면 왼쪽 입력란으로 이동합니다.
3. 상단 목록에서 저장된 템플릿을 즉시 바꿉니다. 위자드는 만들기·수정할 때 사용합니다.
4. **내보내기 → 검토용 PDF**로 시험 출력합니다. 최종 PDF에 미확인 항목이 남으면 **돌아가 수정 / 그래도 출력** 중 선택합니다.

원고 자동 저장은 입력 종료 500ms 뒤입니다. **타이핑 중 미리보기 자동 갱신은 기본적으로 꺼져 있습니다.** 선택한 경우에만 2초 유휴 후 조판하며, 이전 작업의 결과가 새 원고를 덮지 않게 합니다.

## 원고와 이미지

- 안내형 입력과 전체 YAML·고급 보기는 같은 `.md`를 수정합니다. 다른 속성·주석·본문 서식을 보존합니다.
- 외부 편집 충돌 시 양쪽 내용을 보여주고 내 편집 사본을 남깁니다. 잘못된 YAML·조판 실패일 때 이전 PDF를 최신 결과로 저장하지 않습니다.
- Word는 프로젝트 편집본을 수정하며 원본 DOCX를 덮어쓰지 않습니다.
- CMDS Eagle 1.8.4의 내부 편집기 그림 붙여넣기 처리를 검증했습니다. R2 등의 이미지 URL도 미리보기에서 이동할 수 있습니다. 실제 계정 업로드는 검증하지 않았고 시험 서버 응답을 사용했습니다. 원래 Markdown 탭을 요구하는 CMDS 명령은 **원문 열기**에서 사용합니다.
- 비어 있는 선택 정보와 표제는 출력에서 숨기며, 필수 정보 누락은 편집 화면에서 계속 알립니다. 강제 출력은 검사 통과가 아닙니다.
- 기본 HMRI는 원본 PDF, Crossmark는 공식 벡터 SVG를 사용합니다. AF 패키지는 원본 자산·내장 PDF·표시용 미리보기와 해시를 구분합니다.

## 크기와 검증

- `main.js`: **18,290,623 bytes** (18.29 MB / 17.44 MiB). 개발 0.1.1 대비 **417,173 bytes, 약 2.33%** 증가.
- 설치 ZIP: **12,157,062 bytes** (12.16 MB). 의존성 감사에서 보고된 취약점 0건.
- CodeMirror의 편집기 본체는 Obsidian 제공 런타임을 사용합니다. Markdown 언어 지원과 원문 보존용 YAML 파서가 추가됐습니다.
- 타입·빌드·lint·131개 테스트·번들·Community·버전 일치 검사 통과.
- 실제 격리 Obsidian: 미리보기 클릭, 자동 저장, 원문 되돌리기, 외부 충돌, 템플릿 네 종류 전환, 경고 출력, 실패 시 오래된 PDF 차단, Word DOCX 가져오기·수정·재열기 통과.
- 실제 CMDS Eagle 붙여넣기 처리기와 원격 그림 드래그·배치 유지 통과.
- Affinity 저장·재열기: 본문 6개 연결 프레임과 본문 텍스트 해시 유지. HMRI 원본 PDF 바이트 유지. Affinity PDF 재출력에서도 벡터 유지.

## 설치와 확인

설치 ZIP에는 `main.js`, `manifest.json`, `styles.css` 세 파일만 포함합니다. 기존 플러그인 폴더에 이 세 파일을 갱신하고 플러그인을 다시 로드합니다. `data.json`, 사용자 템플릿과 프로젝트를 삭제하거나 초기화하지 않습니다. 설정의 버전 표시가 **0.2.0**인지 확인하세요.

Achmage에서는 기존 0.1.0 설치 파일을 백업하고 세 파일을 갱신했습니다. 설정 파일 보존과 설치 파일 해시 일치, 실제 로드 버전 0.2.0, 수동 미리보기 기본값, 갱신 버튼·안내형 입력란·템플릿 선택 메뉴까지 확인했습니다.

0.1.0 설치본과 0.1.1 개발·공개본의 차이를 이번 버전에 포함했습니다. GitHub에 0.2.0을 공개 게시하거나 Community 등록을 완료했다는 의미는 아닙니다.

## 알려진 범위

Affinity의 PDF Passthrough는 편집 화면에 비트맵 미리보기를 표시합니다. 이번 저장 시험에서는 HMRI 표시용 이미지가 750×232에서 122×38로 재생성됐지만, 내장 원본 PDF와 출력 벡터는 보존됐습니다. 화면 확대의 픽셀과 실제 출력 열화를 구분해야 합니다. 표시 해상도를 Affinity 저장 후에도 유지하는 동작은 아직 해결·보장하지 않습니다. [공식 배치 PDF 설명](https://affinity.help/publisher2/en-US.lproj/pages/Media/placeImages.html).

macOS 실기, 모든 한글 IME/타사 테마 조합, 실제 R2 계정 업로드는 이번 시험 범위 밖입니다. AF에서 한 수정이 Markdown으로 역반영되지는 않습니다.
